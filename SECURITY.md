# Security Policy

## Supported Versions

FundChain is a proof-of-concept learning project. The current `main` branch is the only supported version.

## Reporting A Vulnerability

Please do not open public issues for sensitive security reports.

To report a vulnerability, contact the maintainer through GitHub:

- Repository: https://github.com/Abdelkrim7Be/crowdfunding-dapp
- Maintainer: https://github.com/Abdelkrim7Be

Include:

- A clear description of the issue.
- Steps to reproduce it.
- Affected files or contract functions.
- Potential impact.
- Any suggested fix, if available.

## Important Notice

This project has not been professionally audited and should not be used with real funds. It is intended for local development, education, and portfolio demonstration.
